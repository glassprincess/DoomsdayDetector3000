# DDD - Doomsday Detector

Консольная проверка `javaw.exe` под Doomsday. Windows x64, запуск от имени администратора.

Один скан: сигнатуры в памяти и имена классов из JVM. Текущая версия: **0.1.1**.

## Что проверяет

- 46 сигнатур из `data/signatures.json` в UTF-8 и UTF-16LE. База вшита в exe через `include_str!`.
- Имена классов из живой JVM: lowercase+digit имена, короткий пакет с хаотичным именем, плотность коротких обфусцированных имён в начале списка.

Дамп классов на диск не пишется. Системные службы не сканируются.

## Как читать результат

- **Красный:** найдено совпадение с сигнатурой из базы.
- **Жёлтый:** найдены подозрительные имена классов. Эвристика сама по себе не подтверждает наличие чита.
- **CLEAN:** известные сигнатуры не найдены в прочитанной памяти. Это не гарантия отсутствия чита и не итог проверки классов: она выполняется отдельно.
- **INCOMPLETE:** часть выбранной памяти не удалось прочитать либо не прочитано ни одного байта. Показаны пропущенный объём и число неполных регионов; зелёный CLEAN не выводится. Уже найденные сигнатуры сохраняются.

Для проверки плотности имён окно составляет первые 10% классов, максимум 300. Проверка применяется только при размере окна от 25 имён; порог срабатывания: 25 коротких имён либо 20% окна.

Если JVM не удалось разобрать, указатель недоступен, обнаружен цикл или превышен лимит обхода, проверка классов заканчивается ошибкой. Неполный список не выдаётся за успешную проверку.

Чтение классов проверено на отдельных тестовых процессах HotSpot 21.0.10 и 26.0.1. На проверенной Java 8u481 таблица JVM не содержит нужного поля `ClassLoaderData::_klasses`: проверка классов недоступна, сигнатурный скан памяти выполняется отдельно.

## Сборка и проверки

Нужен Rust для Windows x64 с MSVC toolchain и установленными средствами сборки Visual C++.

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

Результат: `target\release\ddd.exe`. Тесты обхода JVM читают искусственные структуры в памяти собственного тестового процесса; для них не нужен Minecraft.
