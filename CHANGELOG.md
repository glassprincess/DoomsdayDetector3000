# Изменения

## 0.1.1 — 2026-11-26

- Неполное чтение памяти больше не выдаёт зелёный CLEAN. Добавлены счётчики пропущенных байтов и неполных регионов.
- Частично прочитанные данные учитываются, найденные сигнатуры сохраняются при последующих ошибках чтения.
- Ошибки запроса регионов памяти показываются как ошибка сканирования.
- Обход JVM проверяет обязательные поля и чтение указателей, останавливается на циклах и после миллиона узлов каждого вида.
- Удалено требование неиспользуемых полей CompressedOops. Смещения полей классов определяются один раз перед обходом.
- Длина и содержимое имени Symbol читаются по смещениям из VMStructs, без фиксированных адресов полей.
- Эвристики имён классов выводятся жёлтым как подозрение. Для проверки плотности коротких имён нужно окно минимум из 25 классов.
- База без рабочих сигнатур отклоняется при загрузке.
- Добавлены тесты ошибок чтения, границ блоков, обхода JVM и порогов эвристик.

База сигнатур не менялась. Точность обнаружения на разных версиях Minecraft и JVM отдельно не измерялась.
